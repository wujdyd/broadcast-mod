# 广播站 Broadcast（Minecraft 1.20.1 + Forge 模组）

校园 / 火车站风格广播系统模组。当前版本：**0.0.3br**

构建产物：`build/libs/broadcast-0.0.3br-all.jar`（内含 MP3/FLAC 解码器，已 reobf，直接放进 `mods/`）。

---

## 方块与物品

| 名称 | 说明 |
| --- | --- |
| 广播站 | 核心方块；多频率、音乐库、网络音乐、播放列表 |
| 挂墙式 / 吸顶式 / 落地式 / 柱式挂壁音响 | 四种广播器，模型各不相同，按频率连接广播站/话筒 |
| 话筒 | 红石控制；GUI 可设频率、红石模式、暂停音乐、开启提示音 |
| 便携式麦克风 | 手持使用；右键开始/停止讲话，Shift+右键打开独立 GUI；无耐久 |
| 广播调试器 | 唯一打开各 GUI 的工具；450 点耐久；可合成 |
| 广播指示灯 | 任意位置可放，当同维度有话筒/广播站广播时亮起 |

其他：频率制、多频率同步、音乐搜索、音乐 UID、删除确认、定时播放列表（二级 GUI）、原生 MP3/FLAC、网络视频音频、音频字幕、可配置声音半径、配方书自动解锁。

## 0.0.3br 更新

- 调试器耐久与客户端同步，损坏时播放原版工具损坏音效；物品名称下方不再显示额外小字。
- 单人 ESC 暂停时挂起 OpenAL 音源，恢复后继续。
- 播放中新增同频率广播器只追加音源，不重置播放进度。
- 播放列表改为真实曲目结束驱动（客户端播放完当前曲目后通知服务端切歌）；二级 GUI 固定显示“正在播放”，下方“将要播放”每页 5 首，页数不限。
- 支持 FLAC（内置 jFLAC，8/16 bit）。
- 网络音乐页支持视频链接：服务器安装 `yt-dlp` 与 `ffmpeg` 后，可解析 B站/抖音/快手/YouTube/TikTok 等平台并转成音频播放。
- 播放时 HUD 底部显示音频字幕（曲名 / 话筒广播中）。
- 指示灯改为连接式：调试器右键指示灯，再右键广播站/广播器/话筒；选择与连接瞬间有粒子，完成后无粒子，亮度 5，连接不耗耐久。
- 话筒提示音在采集初始化前播放；服务端话筒不可用时自动回退到玩家客户端采集；失败消息只发给广播器附近玩家。
- 便携式话筒可使用 300 格内的同频广播器。
- 权限组频率段（默认）：普通 0-40 纯数字；OP2 41-100 纯数字；OP3 任意（含英文）。可用 `/? band` 调整。
- 干扰：OP3 放置的广播器 100 格内压制其他权限广播器；OP2 放置的广播器 100 格内压制普通玩家广播器。

## 构建

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\build.ps1
```

或：

```powershell
$env:JAVA_HOME = "$PWD\tools\jdk17\jdk-17.0.20.1+1"
$env:Path = "$env:JAVA_HOME\bin;$env:Path"
.\tools\gradle-8.1.1\bin\gradle.bat build --no-daemon
```

产物：

- `build/libs/broadcast-0.0.3br-all.jar` —— **发布用**（含 JLayer/jFLAC）
- `build/libs/broadcast-0.0.3br.jar` —— 不含内置依赖
- `media-support/build/libs/broadcast_media_support-1.0.0.jar` —— 视频音频附属（可选）

## 调试器（GUI 打开方式）

- 普通右键方块**不会**打开 GUI，只会提示需要调试器。
- 手持广播调试器右键广播站/广播器/话筒即可打开对应界面。
- **450 点耐久**，每次保存配置扣除：
  - 配置话筒：**3 点**
  - 配置任意广播器：**4 点**
  - 配置广播站（频率/播放列表/循环设置）：**5 点**
  - 仅打开 GUI、播放/停止、音量、红石开关不扣耐久。
- 耐久耗尽后调试器损坏；可重新合成。
- 调试器命令 `/ ? give TSQ` 已删除，只保留合成获取。

## 频率

1. 用调试器打开广播站 →「频率」页签；默认 `CH1`，最多 8 个。
2. 用调试器打开广播器/话筒，设置相同频率。
3. 广播站播放送到所有持有这些频率的广播器；话筒只向**同频率且 10 格内**的广播器讲话。
4. 话筒 GUI 可设置：
   - 红石模式（仅话筒 / 话筒+全部广播器 / 常开）；
   - 讲话时暂停音乐；
   - 开启提示音开关（默认开）：话筒开始广播时播放一次铃声，可在 GUI 关闭。

## 便携式麦克风

- 右键：开始/停止讲话（再次右键停止）。
- **Shift+右键**：打开独立 GUI，设置频率与“讲话时暂停音乐”。
- 音频采集自玩家客户端本机麦克风，服务端转发给同频率、10 格内的广播器。
- 无耐久；玩家下线/换维度/丢下物品时会自动停止。

- 可放在任意位置（不需要支撑）。
- 同维度有话筒在广播或广播站在播放时亮起，亮度 15；停止后熄灭。

## 广播站 GUI

四个页签：音乐库（搜索/UID/删除确认/播放列表入口）、网络音乐、频率、设备管理。
音乐库删除按钮两段确认；服务端删除需要 OP，或使用指令。

### 播放列表（二级 GUI）

左侧音乐库、右侧播放列表；`>`/`<` 添加/移除；循环、顺序/逆序、间隔、最长单首时长；数值框滚轮调整（类机械动力）。旧版固定定时循环已废弃。
“正在播放”固定显示当前曲目；“将要播放”每页 5 首，可翻任意页。

### 上传音乐

服务端 HTTP 端口默认 8790，文件保存到 `broadcast_music/`，自动分配 8 位 UID（小写字母开头，小写字母+数字）。
游戏内「设备管理」点击上传卡片，或浏览器 `http://服务器IP:8790/`，或 `curl -T 歌.ogg "http://服务器IP:8790/upload?name=歌.ogg"`。

## 指令（`/?`）

| 指令 | 说明 | 权限 |
| --- | --- | --- |
| `/? list command` | 列出指令 | 所有人 |
| `/? list music` | 列出 UID + 文件名 | 所有人 |
| `/? list recipe` | 列出已加载的本模组配方 | 所有人 |
| `/? band <max\|cr\|su> <起始:终了> <yes\|no>` | 设置权限组频率段（OP3） | OP3 |
| `/? delete musichub sure <UID>` | 删除音乐 | OP |
| `/? restart` | 重启上传服务 + 重扫音乐库 | OP |
| `/? stopweb` / `/? startweb` | 停止 / 启动上传服务 | OP |

> `/? give TSQ` 已取消；调试器请用配方合成。

## 频率权限与干扰

默认频率段：

- 普通玩家（su）：0-40，仅纯数字
- OP2（cr）：41-100，仅纯数字
- OP3（max）：0-999999999，可用英文

`/? band su 0:40 no`、`/? band cr 41:100 no`、`/? band max 0:999999999 yes` 可调整并保存到 `world/broadcast_bands.json`；su/cr 频率段不能交叉（max 为无限制组）。

## 配置

`config/broadcast-server.toml`：

```toml
[upload]
enabled = true
port = 8790
bind = "0.0.0.0"
dir = "broadcast_music"
maxFileMB = 64

[mic]
capture = "auto"        # auto / server / client
detectionRadius = 10

[audio]
speakerRadius = 18
```

附属的配置在 `config/broadcast_media_support-common.toml`。

## 网络视频音频（需要独立附属）

视频链接由独立附属 **Broadcast Media Support** 处理，主 jar 不内置 yt-dlp/ffmpeg。

安装：

- `broadcast-0.0.3br-all.jar`（主模组）
- `broadcast_media_support-1.0.0.jar`（附属，放在 `mods/`）

未安装附属时，播放视频链接会提示：

```text
未安装broadcast media support，无法播放
```

附属首次使用会自动下载 `yt-dlp`（约 17MB）和 `ffmpeg`（约 80MB）到 `config/broadcast_media_support/tools/`，支持 Windows / Linux / macOS。不能联网的服务器可手动放置工具并在 `config/broadcast_media_support-common.toml` 填绝对路径。

解析结果缓存为 `broadcast_music/video_<hash>.mp3`。普通音频直链和本地音乐不需要附属。

## 多人联机「无效会话」

这是 Mojang 正版会话验证失败，不是本模组网络错误：

1. 离线朋友服：服务端 `online-mode=false`；
2. 正版服：正版账号，且能访问 `sessionserver.mojang.com`；
3. 客户端与服务端安装同一个 `broadcast-0.0.3br-all.jar`；
4. 局域网由主机账号验证。

网络协议：`0.0.3br2`（版本不一致会被 Forge 拒绝）。
